# agents

Claude Code plugin. Principles live in [AGENTS.md](AGENTS.md).

- `/pr-review` runs verbosity, architecture, DRY and correctness reviewers (Sonnet) in parallel.
- `/visualize` makes a graphical HTML explainer of the work done.

Install:

```
/plugin marketplace add BasilJ-S/agents
/plugin install basil-agents@basil-agents
```
